## 🚀 Key Project Contributions
- **Built an NLP-based fake news classification pipeline**
Designed an end-to-end machine learning workflow including text preprocessing, feature engineering (TF-IDF), and supervised learning models to classify news articles as real or fake.
- **Developed and optimized machine learning models**
Trained and evaluated multiple models (e.g., Logistic Regression and Transformer-based approaches) to improve classification performance and ensure reliable predictions.
- **Implemented a REST API for real-time inference**
Created a FastAPI service to serve the trained model, enabling real-time fake news detection through simple HTTP requests.
- **Containerized the application for deployment**
Packaged the entire system using Docker to ensure reproducibility, portability, and smooth deployment across different environments.
