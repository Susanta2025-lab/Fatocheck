## 🚀 Project Overview

**FatoCheck** is a production-grade fake news detection system designed to identify misinformation using a **two-tier AI architecture**:

- 🧠 Classical ML pipeline (TF-IDF + XGBoost/LogReg)
- 🤖 Transformer-based deep learning (BERT)

It combines **high-performance NLP modeling, scalable APIs, and containerized deployment** into a single MLOps-ready system.
